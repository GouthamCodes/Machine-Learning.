                                           **Weather Forecasting using Machine Learning**

This project utilizes machine learning techniques to predict weather patterns. The development process involved the following steps:

1. Data Preprocessing: Utilized the pandas library to process and structure the data into a suitable format for analysis.
2. Feature Engineering: Employed the Label Encoder algorithm to convert categorical string variables into numerical integer values, enabling the model to effectively process and learn from the data.
3. Model Development: Implemented a Decision Tree algorithm to build a predictive model, leveraging the processed data to forecast weather patterns.
4. Model Evaluation: Utilized the Train-Test Split technique to assess the model's performance, achieving an accuracy of 40% using the Decision Tree algorithm.
5. Model Deployment: Saved the trained model using Pickle and deployed it as a web application using the Streamlit library, providing an intuitive interface for users to interact with the model and obtain weather forecasts.

**Key Technologies Used**

- pandas for data preprocessing and structuring
- Label Encoder for feature engineering
- Decision Tree algorithm for model development
- Train-Test Split for model evaluation
- Pickle for model saving and loading
- Streamlit for model deployment and web application development
